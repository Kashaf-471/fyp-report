# Zeest planned wireframes

Owner: Kashaf. These are proposed physician interface designs, not implemented prototype screenshots.

- Patient History (W01): UC01; FR01 and FR02.
- Consultation (W02): UC02 and UC03; FR03 through FR08.
- Review and Audit (W03): UC04 through UC08; FR09 through FR15.

Each view has an editable, self-contained `code.html` and a rendered `screen.png`. Open any HTML file in a browser; navigation links connect the three views. No external fonts, CDN scripts or simulated clinical operations are used. Buttons are static design controls. Modifying a draft does not approve a clinical decision.

Use Arial, charcoal text, white panels, subtle grey borders and muted blue for active navigation and primary actions. Red outlines identify rejection. Keep placeholders for identifiers, inputs, findings and citations; never add invented clinical data or verification claims. Technical requirement mappings belong in report captions and the GUI mapping table.

The report uses matching owner-prefixed images under `Report template/Figures/`. HTML is the current editable source; the older SVG wireframes are earlier drafts and are not used for the current report images.
